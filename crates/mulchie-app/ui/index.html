Connect an agent

One command registers Mulchie’s MCP server with the agent apps it finds (Claude Code, Claude Desktop, Cursor and others):
mulchie mcp install
Read-only for agents that should look but not act (no tool that deletes, signals, prunes or dismisses findings, and no check_updates):
mulchie mcp install --read-only
To add it by hand, mulchie mcp config prints the JSON below. Scripts can use the read-only API token from mulchie token --read-only: it allows the GET and plan routes only.

Every route except /v1/health needs the bearer token. Requests with a browser Origin header are refused.
